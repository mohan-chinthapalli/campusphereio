# Campus Connect Hub

You are an award-winning Senior Product Designer, UX Researcher, and Frontend Engineer from companies like Apple, Linear, Notion, Airbnb, and Google.

Your mission is to design and build the complete frontend of a modern SaaS-quality web application called "CampuSphere".

This is NOT a college project.

This should look like a production-ready startup product that universities would actually purchase.

PROJECT NAME

──────────────────────────────

PROJECT VISION

CampuSphere is a centralized digital campus experience platform.

It is NOT a traditional university ERP.

It focuses on improving student life by combining academics, clubs, events, mentorship, navigation, learning resources, and AI into one modern platform.

When a student opens CampuSphere, they should immediately know:

• What is happening today?

• What opportunities are available?

• What can I learn?

• Where do I need to go?

• Who can help me?

The experience should feel exciting, modern, clean and interactive.

Think beyond dashboards.

Think about creating a digital campus.
